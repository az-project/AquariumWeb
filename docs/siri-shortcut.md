# 시리 단축어로 수질 기록하기

"시리야, 리프로그 기록" → "오늘 인산염 0.01 질산염 3.0" 이라고 말하면 수질 로그에 저장됩니다.

## 1. 서버 설정 (Vercel 환경변수)

```text
REEFLOG_SHORTCUT_TOKEN=<긴 랜덤 문자열>   # 예: openssl rand -hex 32
REEFLOG_TIMEZONE=Asia/Seoul                # 생략 시 Asia/Seoul
```

환경변수를 넣은 뒤 재배포해야 적용됩니다. 토큰이 없으면 엔드포인트는 503을 돌려줍니다.

## 2. 단축어 만들기 (iPhone 단축어 앱)

새 단축어를 만들고 이름을 **리프로그 기록**(원하는 이름)으로 정한 뒤 동작을 순서대로 추가합니다.

1. **텍스트 받아쓰기** — 언어: 한국어, 듣기 중단: 일시 정지한 후
2. **URL 콘텐츠 가져오기**
   - URL: `https://aqua.avokado.co.kr/api/quick-log`
   - 메서드: `POST`
   - 헤더: `Authorization` = `Bearer <REEFLOG_SHORTCUT_TOKEN 값>`
   - 본문 요청: JSON, 키 `text` (텍스트) = *받아쓴 텍스트*
3. **사전 값 가져오기** — 키 `message`, 입력: *URL의 콘텐츠*
4. **말하기** (또는 결과 보기) — *사전 값*

## 3. 말하는 방법

- 날짜: `오늘`, `어제`, `그제`, `2026년 10월 17일` (생략하면 오늘)
- 항목: 인산염/PO4, 질산염/NO3, 아질산염/NO2, 암모니아/NH3, KH/알칼리니티, 염도/비중, 온도/수온, pH, GH
- 숫자는 `0.01`, `3.0`, `영점영일`처럼 말해도 됩니다.

같은 날짜에 이미 기록이 있으면 말한 항목만 갱신하고 나머지 값은 유지합니다.

## API

`POST /api/quick-log` (헤더 `Authorization: Bearer <토큰>`)

```json
{ "text": "오늘 인산염 0.01 질산염 3.0" }
```

또는 숫자로 직접: `{ "po4": 0.01, "no3": 3, "date": "2026-10-18", "tankId": "..." }`
`tankId`를 생략하면 활성 어항에 저장합니다.

응답: `{ "ok": true, "message": "오늘 질산염 3, 인산염 0.01 저장했어요.", "date": "...", "values": {...}, "log": {...} }`
실패 시에도 `message`에 읽어 줄 안내 문장이 들어 있습니다.
